How to Download and Update Firmware on the Symbio™ 700

Applies to: Trane® Symbio™ 700 Unit Controller

Updating the firmware on the Symbio™ 700 Unit Controller Module ensures optimal system reliability, delivers critical security patches, improves energy optimization sequences, introduces bug fixes, and enhances component compatibility across refrigeration and airside sub-assemblies.

There are three approved methods to perform a firmware upgrade:

  1. Method 1: Symbio Service & Installation Mobile App 
  2. Method 2: Symbio 700 On-Board Keypad/Display Interface 
  3. Method 3: Trane® Tracer® TU Service Tool 

 

Prerequisites & Hardware Requirements

CRITICAL WARNING — FILE TRANSFER PRACTICE
DO NOT drag and drop the firmware file onto your USB flash drive. Always Copy & Paste the .bin / package file to prevent hidden file corruption during direct write operations.

 

USB Flash Drive Specifications (Methods 1 & 2 only)

  • Storage Size: Maximum 32 GB (larger capacities like 64GB/128GB are not supported by the bootloader).
  • Format: FAT32 file system. Refer to How to format USB drive to FAT32 if needed.
  • Storage Directory: Place the firmware file in the root directory of the drive (do not bury inside subfolders).

Method 1: Firmware Update Using the Symbio Mobile App (Recommended)

For Method 1 (Mobile App) and Method 2 (On-Board Display):

  • Connect: Open the Symbio Service & Installation App on your mobile device and connect via Bluetooth to the Symbio 700 controller.
  • Navigate: From the primary navigation menu, select Tools.
  • Select Utility: Tap Update Firmware.


  • Select File: The app will scan the connected USB flash drive and display available firmware packages. Select the target version.
  • Initiate Transfer:
    • Tap Update Firmware.
    • In the confirmation dialogue box, tap UPDATE.


 

WHAT TO EXPECT DURING THE 3–5 MINUTE UPGRADE:

  • You will automatically be disconnected from the mobile app.
  • Partway through the sequence, all LEDs on the Symbio 700 board will extinguish momentarily. This is normal behavior.
  • The onboard 2-line display will cycle through the following stages:
    Validating FW ➔ Decrypting FW ➔ Boot Rec ➔ Recovery ➔ Validating FW ➔ Decrypting FW ➔ Updating BLE ➔ Updating FW ➔ Updating Kernel ➔ Updating DT ➔ Updating Boot1dr ➔ Updating Recovery ➔ Update Success
  • The controller will reboot, showing Load Field ➔ Boot Field ➔ Symbio 700 Ready.


Finalize & Verify:

  • Wait until the display reads Symbio 700 Ready.
  • Power down the controller (or cycle control power safely), then remove the USB flash drive.
  • Power up and reconnect with the Symbio Mobile App.
  • Under controller status/information, confirm the new firmware release version is active.


 

Method 2: Firmware Update Using the On-Board Keypad & Display

Use this step-by-step guide to update controller firmware directly at the unit without using a phone or laptop.

Keypad Quick Reference

Before starting, familiarize yourself with the 6-button onboard keypad:

  • Home: Returns to the main status screen.
  • ⬆ / ⬇ [Up / Down]: Scrolls through menu items and options.
  • ✔ [Checkmark / Enter]: Confirms a selection or enters a submenu.

 

Step 1: Insert the USB Flash Drive

  • Verify that the unit and Symbio 700 controller are energized.
  • Insert your FAT32-formatted USB flash drive (≤ 32 GB containing the firmware file) into the USB Host connector (J2) located at the top-left corner of the Symbio 700 board.

 

Step 2: Navigate to the Firmware Update Menu

Follow this key sequence on the controller's onboard interface:

 Home ➔ Scroll Down ➔ Utilities ➔ Press (✔) ➔ Scroll Down ➔ Firmware Update ➔ Press (✔)

  • Press the Home button.
  • Press the Down Arrow (⬇) to scroll down until Utilities is highlighted.
  • Press Enter (✔) to open the Utilities menu.
  • The display will initially show About. Press the Down Arrow (⬇) until Firmware Update appears.

  • Press Enter (✔)

 

Step 3: Select File & Confirm Installation

  • Select File: The display will show the firmware filename found on the USB drive (the text will scroll horizontally from left to right).

    • Press Enter (✔) to select the file.

Immediately upon confirmation, the display will switch to:

CRITICAL SAFETY WARNING — DO NOT INTERRUPT

  • DO NOT turn off or cycle power to the unit.
  • DO NOT remove the USB flash drive.

Method 3: Firmware Update Using Trane® Tracer® TU Service Tool (Trane Technicians)

Launch & Connect: Connect your PC to the controller service port and open Tracer® TU.

File Transfer Utility: Click the Utilities tab, then select File Transfer Utility.

 

Wizard Step 1: Click Next on the introductory screen.

 

Select Firmware: Click Browse, locate and select the downloaded firmware file on your local hard drive, and click Open.

 

Confirm: Confirm your selection and click Next.

 

Initiate Transfer: Click Start.

 

Transfer Progress: The status indicators will display Transferring started followed by Transferring in progress.

 

Controller Sequence: The physical Symbio 700 display will reflect the active update sequence during laptop file streaming.

 

Success & Reboot: Tracer TU will report Transfer Successful. The Symbio 700 will automatically cycle power and display Symbio 700 Ready.

 

Verification: In Tracer TU, navigate to:
Controller Status Tab ➔ Controller ➔ Product Version to confirm the active firmware build.
