Background

When replacing the VFD within the air handler, it is important to program it correctly. A new drive from Trane Parts will not come preprogrammed for the specific unit. The choice of which set of parameters you use is based on the air handler model number. 

 

  • A model with the 7th digit = K will use the Odyssey A2L R454B VFD Parameters. 
    • For example: TWE120K3AAA07BD4000000000000000000000000

 

  • A model with the 14th digit = B will use the Odyssey model 14th digit = B VFD Parameters
    • For example: TWE18043BAA07BC0000000000000000000000000

 

  • A model with the 14th digit = A will use the Odyssey model 14th digit = A VFD Parameters
    • For example: TWE07244BAA05AD0000000000000000000000000

 

For assistance on how to navigate the parameters in the drive for programming, see the article Programming or changing parameters in the TR150 VFD

Quick Transfer of Parameter Setting from the old VFD to the replacement VFD

For a drive that will still power the keypad, it may be faster to transfer the parameter settings with the keypad. The data can be saved to the keypad before the VFD is replaced and then transferred to the replacement VFD.

If the failed drive has no power and it is not able to save the parameters to the keypad, it is recommended once manually installing the parameters in the new drive to save the data to the keypad for any future issues.

If the replacement VFD is having the same issues as the old VFD after data transfer, there may be a parameter outside the replacement list that was changed and copied over to the new drive. For this instance, it may be necessary to restore the VFD to factory defaults and manually install the parameters. If this corrects the issue, save the parameters to the keypad using the instructions: Data transfer from the keypad to the replacement VFD

Data transfer from the old VFD to the keypad

  1. Go to parameter 0-50 LCP Copy
  2. Press [OK]
  3. Select [1] All to LCP
  4. Press [OK]

Data transfer from the keypad to the replacement VFD

  1. Go to parameter 0-50 LCP Copy
  2. Press [OK]
  3. Select [2] All from LCP
  4. Press [OK]
