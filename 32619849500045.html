Retrieving Data Logs with Tracer TU

 

 

  1. Connect to Symbio 700 with Tracer TU via USB or SC+/Synchrony connection.

     

  2. Select the TOOLS drop-down and select RETRIEVE DATA LOGS:




     

  3. In the Retrieve Data Logs window, select the desired data logs and hit RETRIEVE:


     
     

    Note: The default number of samples is 50,000 at 10 seconds each (5.79 days). The time to retrieve each data log at 50,000 samples is about 45-60 seconds with a direct connection, times can be considerably longer with remote connections and connections through AirFi.


     

  4. Once the process has begun, the Progress for each data log will update one at a time:




     

  5. Once status on all selected data logs shows Done, select Close:




     

  6. To access the retrieved data logs, access Documents\Tracer TU\Data Logs\Symbio 700\<select controller type-Odyssey/Precedent/Voyager III>:



     

    Each data log will be present as an individual .csv file .

     

At this time, neither Symbio 700 or Tracer TU combine data logs into one large file. 

Data logs for all like equipment types are stored in the same folder, data logs from two separate units will store in the same folder, recommend pulling each unit's files into a job folder before starting the next data log collection.
