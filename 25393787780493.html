Symbio 700 SCC/DAC LonTalk Integration .xif files

Summary: 

The .xif files in the Symbio 700 SCC/DAC LonTalk Integration package provide a convenient way to integrate the Symbio 700 controllers with the LonTalk communication protocol. This integration allows for seamless communication between the controllers and other Lontalk devices on the network   

 

Symbio 700 can be configured for Discharge Air Control or Space Comfort Control.  The .XIF file is dependent on the configuration of the Symbio 700 Controller. 

 

- Symbio 700 Configured as CVZT or VVZT (SZVAV) will have a SCC Profile with program ID of 8000-2A-5500-0304-20.

 

- Symbio 700 Configured as VVDA (MZVAV) will have a DAC Profile with program ID of 8000-2A-560A-0304-20. 

 

XIF Files for both Program ID's are attached.  

 

Note:  XIF files were created from a Symbio 700 with firmware 5.00.0010.
