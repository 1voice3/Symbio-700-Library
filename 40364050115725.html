Symbio 800 - Connecting to a Symbio 800 with Symbio Service and Installation mobile app

General Symbio 700Firmware / SoftwareSensors / ModulesInstallation / StartupHeating
Section: IntelliPak w/Symbio 800 Controls  •  Category: Large Commercial RTUs | Splits | CSC
Created: 2025-10-15  •  Last updated: 2026-03-17

The Symbio Service and Installation mobile app has been supporting Symbio 700 controllers for several years. Recently, it has also begun supporting the Symbio 800 controllers for Ipak and Chillers. Both Symbio 700 and 800 controllers can connect remotely using Trane Connect using the same procedure.

However, there is a key difference in how the app connects locally to these controllers. For the Symbio 700, the app uses Bluetooth for a local connection. In contrast, the Symbio 800 does not have Bluetooth capability, so it connects locally via a Wi-Fi module which is a different process when compared to a Bluetooth connection.

This document provides instructions on how to establish a local connection or a remote connection from the mobile app to a Symbio 800.

Download Symbio Mobile Phone App

To download the Symbio Service & Installation mobile app:

1. Navigate to the Apple App Store or Google Play Store on your mobile device.
2. Search for Trane Symbio to locate the Symbio Service & Installation app.
3. Download and install the app.
