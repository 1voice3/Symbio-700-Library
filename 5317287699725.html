2-Stage Compressor Information

Some Odyssey dual circuit condensers have utilized 2-stage compressors in the past, but the product line up has expanded to utilize 2-stage compressors on more equipment. All units that utilize a 2-Stage compressor in some fashion will require both Y1 & Y2 thermostat inputs to utilize both compressor stages. Dual circuit units will operate both compressors with a Y1 call in first stage and then full capacity with Y1+Y2. 

 

Dual Circuit Condensers with 2-Stage Compressors

Odyssey 10 and 20 ton dual circuit units that utilized Electromechanical, ReliaTel controls and Symbio 700 controls built through 2022 were the only dual circuit models that utilized 2-Stage Compressors, staging is shown in the chart below. ReliaTel condenser production was ended in Fall 2020.

Note: For Symbio 700 controlled units, the ability for these units to operate the 2-Stage compressors is based on the Symbio 700 firmware and the EFFICIENCY setting in the Symbio 700 configuration.

  • Symbio 700 controlled units built prior to 2023 (serial numbers starting with 20 thru 22) should always be set to EFFICIENCY = STANDARD. 
  • If a 7.5/12.5T TTA or 10/12.5T TWA built before 2023 has the firmware updated and gets EFFICIENCY set to STANDARD B, it will run the unit at 100% capacity as the software thinks there are 2-Stage compressors when there are actually not. 
  • All Symbio 700 controlled units built after 2023 (serial numbers starting with 23 and up) should be set to EFFICIENCY = STANARD B.
