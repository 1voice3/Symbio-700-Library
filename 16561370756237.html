Configuring with Phone App 

From the Home Page, go to the Setting Icon

 

Click the View Configuration tab

This page does not auto-refresh; to manually refresh, swipe down or press refresh

 

 

To edit the configuration, press the Edit button on the next window; you'll see (Stopping the Equipment) press the Proceed button and start the equipment configuration.

 

Note

The apply button will be enabled once all option selections have been made.

Once completed, press the Apply or √ button in the top right corner.

Notes

Note: A complete configuration will be required during a Symbio 700 Unit Controller replacement if you do not have a backup file to restore. All the configuration items must be selected.

Note: These options—Economizer, Relief Fan (Power Exhaust), Clogged Filter Switch, and Condensate Overflow Switch—may be field‑installed. If they are not shown in the model number, confirm whether they are present when setting up the unit controller.

Note: Equipment can be configured through the Tracer TU, the mobile service tool, or the onboard display.

Note 4: When placing the Electric Heat configuration to "Installed", an Indoor Options Module is required. Not required on 3-5 Ton units

The Supply Air Smoke Detector and Return Air Smoke Detector configurations apply only to factory-installed detectors. For a field-installed smoke detector, do not use this configuration.
