Foundation w/ Symbio 700 License Restrictions

All Foundation units sold with Symbio 700 controls come standard with a Basic License and can not be upgraded to Advanced License. 

Controls

Enhanced Connectivity

Symbio™ 700 for Foundation provides Standard Controller functionality which provides advanced troubleshooting, secure remote connectivity via Trane Connect, and access to the Symbio Service and Installation mobile app via a bluetooth connection. 

The Standard controller functionality does not support:

  • BACnet® MSTP / IP
  • Modbus™ TCP / IP
  • Air-Fi® communications
  • Custom TGP2 programming
  • XM30 / XM332 expansion modules
  • Upgrade to an Advanced Controller

The intent of Foundation equipment is to be the basic RTU to meet HVAC needs and to be controlled with a thermostat (3-25T) or a zone sensor on Large Foundation 15-25T. 

 

For sites requesting BAS integration to Foundation units, this is going to require a BACnet thermostat (thermostat w/ conventional thermostat connections and the ability to be on a BACnet network). Trane no longer has an offering for a BACnet Thermostat, THT02298/BAYSTAT300 offering has been discontinued.

 

Kele.com offers multiple options including the Viconics VT7600 series that BAYSTAT300 was based on, 

Another option is to add a Symbio 500 using the 2 Heat/2 Cool program and allow the Symbio 500 to interface with the Foundation unit through the thermostat interface. This also allows the use of the standard Trane zone sensors connected to the Symbio 500. The Symbio 500 also offers the ability to add additional field supplied sensors (DAT, RAT, Fan Proving) for reporting to a BAS. 

 

There is no way to update a Foundation unit with Symbio 700 to an Advanced License. A license can be purchased and even installed, but the Foundation Equipment Type will block all Advance License features and report that a Basic License is installed. Changing the Equipment Type will stop the unit from functioning due to configuration mismatch issues with installed equipment.
