Indoor Options Module

 

Summary:

This kit is required when adding an electric heat or condensate overflow switch accessory. The Indoor Options module operates with the Symbio 700 in the condenser to provide logic control.

 

 

 

 

Click the e-library symbol for the latest version of the installation guide

 

 

 

Note: The Static Pressure Transducer is a factory-installed component on Multi-Zone VAV units. It connectes to IOM-J1.

 

 

Module Address:

 

  • When the Indoor Options module is field-installed, you must set the rotary switches to address 75. This is required to integrate the module with the Symbio controller. If the Indoor Options module was powered up before setting the address, reset it by performing a power cycle or resetting the IMC link. To reset the IMC link, go to Tools > Service > scroll down to IMC LINK RESET.
