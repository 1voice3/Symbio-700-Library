Options Module and Address Requirement

The Symbio 700 module address is the unique identifier assigned to the Symbio 700 module on the network. This address serves as a unique identifier for the module, allowing it to be recognized in the network. The Symbio 700 module's address is critical for establishing communication and interoperability with other connected devices, enabling seamless integration and functionality. It extends its control capabilities through the use of additional hardware modules. These modules are installed, wired, and tested in the unit when ordered from the factory. The modules can be field-installed. The following table summarizes the Symbio 700 functions that require an additional hardware module.

 

3 to 5 Ton Units

Standard efficiency and 3 ton high efficiency cooling only

(a) Customer Options Module sources the Supply Fan Speed Command in 3-ton high-efficiency cooling-only units via a PWM-based speed control signal.

Troubleshooting Communication

An improperly addressed module will create a communication diagnostic.

Indoor Options Module

  • Symbio® 700 Indoor Options Module (IOM) Not Communicating – Trane Commercial HVAC Help Center

Fresh Air Options Module

  • Symbio® 700 Fresh Air Options Module (FAOM) Not Communicating – Trane Commercial HVAC Help Center

Customer Connection Module

  • Symbio® 700 Customer Connection Module (CCM) not communicating – Trane Commercial HVAC Help Center

Stepper Motor Controller

  • Symbio® 700 Stepper Motor Controller (SMC) Not Communicating – Trane Commercial HVAC Help Center
