Compatibility

The BAYSENS800 (Service P/N: X13791009001) is a full-color touchscreen programmable zone sensor designed for standalone HVAC applications using Trane Symbio™ 700 unit controllers.

 

IMPORTANT COMPATIBILITY RESTRICTIONS

  • Incompatible Sensors: The BAYSENS924 is not compatible with the Symbio 700. Only use BAYSENS800 (X13791009001).
  • System Types: Supported on Constant Volume Zone Temperature (CVZT) and Variable Volume Zone Temperature (VVZT) systems. It is not compatible with Multiple Zone VAV (MZVAV) or Variable Volume Discharge Air (VVDA) configurations.
  • Standalone Operation: BAYSENS800 is intended for standalone unit control. Later hardware revisions (e.g., BAYSENS800AB) may be connected to a Building Automation System (BAS) for monitoring purposes only.
  • Dedicated Bus: BAYSENS800 communicates via BACnet MS/TP. If an optional LonTalk® or Air-Fi® wireless adapter is connected to the Symbio 700, it must be disconnected.

 

Unit Controller License Requirements

The Symbio 700 controller must possess an Advanced License to communicate with the BAYSENS800.

Basic Wiring to Symbio 700 (UC)

 

Option A: Remote Sensor(s) Connected to Symbio 700 (Preferred)

  1. Land thermistor leads across the designated zone temperature input terminals on the Symbio 700 board (J16).
  2. In the BAYSENS800 menu, set the temperature source to Remote.

  1. Connect thermistor leads to terminals G and H on the back of the BAYSENS800.
  2. In the BAYSENS800 menu, set UC17 config to Temp and set temperature source to Wired.

Multi-Sensor Averaging Rules

To maintain the correct 10k Ω Type II thermistor resistance curve, sensor averaging networks must utilize a square number of identical sensors wired in series-parallel:

  • 4 Sensors: 2 parallel strings of 2 sensors in series.
  • 9 Sensors: 3 parallel strings of 3 sensors in series.
  • 16 Sensors: 4 parallel strings of 4 sensors in series.
  • 25 Sensors: 5 parallel strings of 5 sensors in series.

For complete schematic wiring diagrams, refer to How to average multiple zone temp sensors.

 

Recommended Communication Cable

BACnet MS/TP communication requires low-capacitance, shielded twisted pair (STP) cable:

  • Approved Supplier: Windy City Wire
    • Plenum-Rated: P/N 043005AL
    • Non-Plenum Rated: P/N 108760
  • Alternative Cable Specifications:
    • Conductor Gauge: 22 AWG to 18 AWG stranded twisted pair with shield.
    • Characteristic Impedance: 100 to 130 Ω.
    • Capacitance (Conductor to Conductor): <100 pF/m (<30 pF/ft).
    • Capacitance (Conductor to Shield): <200 pF/m (<60 pF/ft).
Configuration

Controller Configuration

Set Physical Rotary Dials

Set the physical rotary address dials on the face of the Symbio 700 module to 001.

 

Configure via the Symbio Service & Installation Mobile App

  1. Connect to the Symbio 700 using Bluetooth via the Symbio Service & Installation App.
  2. Enable External Control:
    • Go to Settings > System.
    • Set Arbitration Method Request to Enable External BAS Control.
      •  Settings > System with Arbitration Method Request toggled/set to Enable External BAS Control.

 

Configure Space Controller:

  • Navigate to Settings > View Configuration > Edit.
  • Set Space Controller Type to Single Setpoint Zone Sensor.
  • Verify that System Type is configured as CVZT or VVZT (VVDA and MZVAV are not supported).

    • View Configuration > Edit highlighting Space Controller Type = Single Setpoint Zone Sensor.

 

Configure BACnet Protocol:

  • Navigate to Tools > Protocol Configuration > Protocol.
  • Select BACnet MS/TP.
  • Set the Baud Rate to 76800 bps.
  • Tap Save.
    • Tools > Protocol Configuration with Protocol set to BACnet MS/TP and Baud Rate set to 76800.

 

BAYSENS800 On-Screen Configuration

Entering Technician Configuration

  1. Tap the touchscreen display to wake the sensor.
  2. Press and hold the lower right corner (or settings icon) for 5 seconds.
  3. Enter the Technician Passcode: 4017.

 

Network Setup

Both devices must reside on the same MS/TP network with matching baud rates and unique MAC addresses/Device IDs.

Legacy Firmware (2 Network Configuration Pages)

  • Sensor Address (MAC): 2
  • Unit Address (MAC): 1
  • Baud Rate: 76,800

Current Firmware (3 Network Configuration Pages)

  • Network Page 1:
    • Sensor Address: 2
    • Baud Rate: 76,800
  • Network Page 2:
    • Sensor Device ID: 0000002
  • Network Page 3:
    • Unit Device ID: 0000001

TIP: Ensure you press the Right Arrow / Next button through all pages to commit and save the parameters to non-volatile memory.

 

Remote Thermistor Input Setup

If an external thermistor is being utilized instead of the sensor's internal thermistor:

  • When wired to Symbio 700 (Option A):
    1. Go to Configuration Page 2.
    2. Set Temp. Sensor to Remote.
  • When wired directly to BAYSENS800 (Option B):
    1. Go to Configuration Page 2.
    2. Set UC17 config to Temp.
    3. Set Temp. Sensor to Wired.

How to Enter Configuration Mode

The BAYSENS800 touchscreen provides access to the password-protected installer setup screens through a hidden touch gesture on the home screen:

  1. Ensure the sensor is powered on and displaying the Home Screen (showing indoor temperature, occupancy, and time).
  2. Touch and hold the top center location of the display glass for 2 seconds.
  3. Release your finger when the display transitions to the Installer Password keypad screen.
Interactive simulation note: Click the dashed [Touch Top Center (2s)] hotspot on the virtual sensor above to launch the password screen immediately.

How to Enter the Password

All installer menus require the factory password:

  1. On the Installer Password screen, use the numeric keypad buttons 0 through 9.
  2. Enter the fixed installer password: 4 0 1 7.
  3. Once the fourth digit is entered, the sensor automatically validates the passcode and unlocks the 1 / 2 Setup screen.
Important: The installer password is fixed at 4017 and cannot be modified in the field.

How to Configure Network Settings (1/3 Network Settings & Figure 4)

Proper MS/TP token passing requires matching communication parameters between the Symbio 700 controller and BAYSENS800:

  1. From the 1 / 2 Setup menu, select Network.
  2. On 1/3 Network Settings (or 1/2 in legacy firmware), configure:
    • Sens. address: Set to a unique BACnet MAC address (typically 2 on a dedicated sensor link; range 0–127).
    • Baud rate: Must match the Symbio 700 baud rate exactly (default: 76800).
    • Status: Displays online when valid token frames are detected. If incorrect, it indicates offline.
  3. In older firmware, set Unit address to match the rotary dial on the Symbio 700 (typically 1).
If the sensor address, unit address, or baud rate is incorrect, communication will fail completely, causing the Symbio 700 space temperature to register 1000001°F.

2/2 Network Instance / 2/3 Sensor Device ID & The [R] Button

BACnet device instance numbers must be correctly formatted to prevent network conflicts:

  1. Navigate to 2/2 Network Instance (or 2/3 Sensor Device ID on updated Figure 4 firmware).
  2. If the displayed instance shows an unconfigured or unexpected number:
    • Press the [R] button on the touchscreen.
    • Touching [R] automatically copies the sensor MAC address number into the BACnet Device ID field, resetting it to 000002 (or 0011002).
  3. Press the checkmark button (✓) to confirm and save the new instance value.
Figure 4 Note: Modern firmware includes separate pages: 2/3 Sensor Device ID and 3/3 Unit Device ID. Verify both IDs align with your BACnet network plan.

How to Configure 2/4 Configuration (UC17 & Temp Sensor)

Terminals 17 and 18 can be configured for auxiliary sensing or remote temperature:

  1. From the 1 / 2 Setup screen, tap Configuration.
  2. Advance past 1/4 Configuration to page 2/4 Configuration.
  3. Set UC17 config:
    • None: Terminals 17 and 18 are not in use (standard installation).
    • Motion: Connected to a remote dry contact occupancy/motion sensor.
    • Temp: Connected to an external 10k Type 2 thermistor sensor.
  4. Set Temp. sensor:
    • Internal: Uses the sensor's high-precision on-board thermistor (default).
    • Remote: Uses an external sensor wired directly to the HVAC equipment.
    • Wired: Uses the external sensor landed on terminals 17 and 18.
If the wired or remote sensor fails, the BAYSENS800 automatically fails over to its internal 10k sensor element.

How to Enter Service View 4/7 & Verify Online Status

Service View allows field technicians to monitor real-time controller telemetry and diagnostics without specialized software:

  1. From the 1 / 2 Setup screen, select Service View.
  2. Use the screen advance buttons to scroll to page 4/7 Service View.
  3. Inspect the Unit status field:
    • Online: Indicates active bidirectional BACnet MS/TP communication with the Symbio 700.
    • Offline: Indicates broken communication. Check polarity (J17-1 to C, J17-2 to D), baud mismatch, or address collision.
  4. Also verify that the sensor failure diagnostics (DAT sensor fail, OAT sensor fail, etc.) show Off.

How to Verify Lua 1/3 (Trane_Symbio-v)

The BAYSENS800 uses custom embedded Lua scripts to translate points for specific Trane controllers:

  1. From the 1 / 2 Setup screen, advance to 2 / 2 Setup.
  2. Select Lua to enter the firmware verification menu.
  3. On page 1/3 Lua, verify that the top header reads: Trane_Symbio-v1. :
  4. Confirm the hardware part number reads X13791009001 (BAYSENS800).
  5. Confirm the client description reads: Network Client for Symbio 800 rev 1.3.8 (based on Trane rev 6.11).
Compatibility: Sensors programmed with Symbio 800 Lua are fully compatible with Symbio 700 controllers. If the Lua screen displays Trane_ReliaTel-V or Trane_UC400, the sensor is the wrong model for this unit.

Wiring Needed

The Programmable Zone Sensors only support the BACnet MS/TP communication protocol for integration to either Trane or non-Trane control systems.

Communication Wire

Use the correct communication wire to ensure reliable communication between the zone sensor and the HVAC equipment.

Recommended supplier: Windy City Wire
  • Plenum rated P/N: 043005AL
  • Non-plenum rated P/N: 108760

Other wire may be used if it conforms with the following physical characteristics:

  1. Twisted pair (2-conductor) plus shield
  2. Characteristic impedance: 100–130 ohms
  3. Distributed capacitance between conductors: <100 pF/m
  4. Distributed capacitance between conductor and shield: <200 pF/m
  5. Foil or braided shield is acceptable
  6. Maximum length (end to end): 4000 ft with 18 AWG conductor wires
  7. Maximum length (end to end): 2000 ft with 22 AWG conductor wires

Configuring the Unit (Symbio 700)

Recommended: configure via the Symbio Service & Installation Mobile App rather than the Symbio's own local keypad/display.

1. Connect & Enable External Control

  1. Connect to the Symbio 700 using Bluetooth via the Symbio Service & Installation App.
  2. Go to Settings > System.
  3. Set Arbitration Method Request to Enable External BAS Control.
Settings > System with Arbitration Method Request toggled/set to Enable External BAS Control.

2. Configure Space Controller

  1. Navigate to Settings > View Configuration > Edit.
  2. Set Space Controller Type to Single Setpoint Zone Sensor.
  3. Verify that System Type is configured as CVZT or VVZT (VVDA and MZVAV are not supported).
View Configuration > Edit highlighting Space Controller Type = Single Setpoint Zone Sensor.

3. Configure BACnet Protocol

  1. Navigate to Tools > Protocol Configuration > Protocol.
  2. Select BACnet MS/TP.
  3. Set the Baud Rate to 76800 bps.
  4. Tap Save.
Tools > Protocol Configuration with Protocol set to BACnet MS/TP and Baud Rate set to 76800.

Which BAYSENS800 Manual to Use

Two different BAYSENS800 manuals are published, covering two different firmware generations of the sensor. Using the wrong one for the unit in front of you is a common source of confusion during setup and troubleshooting.

BAS-SVN028*-EN — covers the legacy firmware BAYSENS800. Use this manual for older, previously-installed sensors that predate the current firmware revision.
BAS-SVP080*-EN — covers the current firmware BAYSENS800. Use this manual for new installations and any sensor shipped with the latest firmware.

If the menu screens or wording on the physical sensor don't match what a manual describes, check the other one — it usually means the sensor is running the other firmware generation.
