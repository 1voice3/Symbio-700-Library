How to change dehumidification control from relative humidity to humidistat

Dehumidification Control Configuration

 

Notes

  • Dehumidification control is a mode of Cooling when hot gas reheat is configured.
  • Relative Humidity uses a humidity sensor connected to UC-J23.
    • https://support.trane.com/hc/en-us/articles/4544884023693-How-do-I-wire-a-BAYSENS036-037-Humidity-Temp-Sensor-for-Symbio-700-and-Reliatel-Controls
  • Humidistat connects to the Customer Connection Module (CCM) on CCM-J3 terminals 1 and 2.

 

Configure as follows

  • Go to Settings> View Configuration
  • Top right-corner Edit
  • Change Dehumidification Control from Relative Humidity to Humidistat
  • Change or verify the Humidistat is to Install
  • Change Humidity Sensor to Not Install
  • Press Save on the top right-corner to save the configurations
