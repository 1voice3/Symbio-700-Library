Bluetooth Disable

Some government facilities and high-security sites require disabling Bluetooth on the Symbio 700 board. 

 

Disable Bluetooth

Before you start, ensure the firmware version on the Symbio 700 is V2.00.0023 or later. 

  • Firmware Update
    • https://support.trane.com/hc/en-us/articles/23351688731405-Symbio-700-Firmware-Update-for-Unit-Controller-Module
  • You can disable Bluetooth through the user interface on the Symbio 700 board by following the steps below.

  1. Select the Home button to start the main menu

  2. Scroll down to Utilities

  3. Select the check mark

  4. Scroll down until Communication is displayed

  5. Select the check mark

  6. Disable Bluetooth/Enter to Disable should be displayed

  7. Select the check mark to disable the Bluetooth

  8. Are you sure? will be displayed

  9. Scroll down to Yes

  10. Select the check mark

  11. Bluetooth Not Allowed will now scroll across the display

 

Notes

  • The only way Bluetooth can be re-enabled is through a reset caused by:

Notes: 

  • Changing equipment type - This will clear out the configuration and the Symbio 700 will need to be re-configured. 
  • Applying a backup - The backup must be before Bluetooth is disabled. 
  • Performing a factory reset - This will clear out the configuration and the Symbio 700 will need to be re-configured.
