Symbio 700 - How to change Baud Rate using the onboard display for Precedent and Odyssey

Change Baud Rate using the onboard display

 

Onboard Display

Using the Symbio 700 Onboard menu and keypad

  1. Press Home.
  2. Press the Down Arrow and select Utilities.
  3. Press the Check mark.
  4. Press the Down Arrow and select Comm Protocol Settings.
  5. Press the Check mark.
  6. Press the Down Arrow and select Baud Rate.
  7. Press the Check mark.
  8. Change the Baud Rate to the desired rate and press the Check mark.

 

 

Note

 

  • You must have an Advanced Symbio 700 controller.
  • Digit 21 of the Precedent and Odyssey units indicates the Symbio board license version
    • Digit 21 = 1 - Advanced license w/ BACnet
    • Digit 21 = 2 - Advanced license w/ Lon
    • Digit 21 = 3 - Advanced license w/ AirFI
