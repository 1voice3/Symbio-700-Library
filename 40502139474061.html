Fresh Air Options Module Overview:

 

Summary:

This Fresh Air Options Module kit is required when adding a 0-50% motorized damper, 0-100% economizer, power exhaust, or clogged filter accessory. The module operates with the Symbio 700 to provide logic control. 

 

 

 

 

 

Click the e-library symbol for the latest version of the installation guide.

 

 

  • When adding a field-installed economizer that is shipped from the factory as a multi-speed (CVZT) unit, a discharge air sensor kit is required.
  • The discharge air sensor is factory-installed when the unit is shipped from the factory, either as a single-zone (VVZT) or multi-zone (VVDA) unit.

Module Address:

 

 

  • When the Fresh Air Options module is field-installed, you must set the rotary switches to address 76. This is required to integrate the module with the Symbio controller. If the Fresh Air Options module was powered up before setting the address, reset it by performing a power cycle or resetting the IMC link. To reset the IMC link, go to Tools > Service > scroll down to IMC LINK RESET.
