Symbio® 700 - Options Module Communication Errors in Tracer TU

 

Summary:

The Options Modules used in Odyssey, Precedent, and Voyager III products are supplied from two different manufacturers and carry two different hardware part numbers. Below are the manufacturers and their corresponding hardware part numbers (as shown in Tracer TU):

NXP – 13651736

Renesas – 4003122

Both boards are covered by the same part numbers

  • X13651736001 for FA OM, Indoor OM
  • X13651736002 for Customer OM

The only way so far to tell them apart is to see the discovered hardware PN in TU or the placement of the serial number QR code on the boards themselves:

Renesas Boards

NXP Boards

 

 

There are two known issues with the modules built by Renesas:

Issue #1

It has been found that older version 1 Symbio firmware will not communicate with the Renesas modules. The issue is that when Symbio sees the module and address, it expects to see a hardware part number consistent with the address it also sees. For example, if you have a module installed as address 75, Symbio will discover it and expect to see one of the two hardware part numbers. The issue is on version 1, it will see 4003122 and not know what it is as it is not part of the v1 firmware. The resolution is to upgrade the firmware to the latest version.

With v1 firmware, you will this error in TU:

  

When you see this error in TU, you will also have comm errors for the Options Module and features configured to that OM.

 

After upgrading to the latest firmware, you may still get an error in Tracer TU based on the TU version:

Tracer TU v11.6 and older

This error has only been seen on the Renesas Options Modules, but the OM will communicate and function normally with no alarms in Symbio. 

 

Same Renesas OM and Symbio700 firmware 3.00.0012 on Tracer TU v11.7

 

 

Issue #2

It has been found that some Renesas boards did not get their hardware part number flashed to them correctly before they were shipped to their final destinations. Most were corrected in the factories, but some may still be found through parts counters.

These boards will not communicate at all as the discovered hardware part number is incomplete on discovery and Symbio does not know what it is. The only resolution is to replace the board. The error message will display the incomplete part number as 40031.

 

 

If you come across a module with this specific error message on a Renesas board, document the serial number on the QR code and report to Trane Tech Support.
