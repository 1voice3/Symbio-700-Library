Symbio™ 700 - Unit Controller License Upgrade from Basic to Advanced

 

Summary:

The Symbio 700 license upgrade allows users to upgrade their existing main Symbio 700 Unit Controller from a Basic to an Advanced license. With the Advanced license, users can access automation capabilities and customization options.

Symbio 700 is available in 2 versions to meet the diverse applications in which this controller will be used. The Basic Version is typically used in a setting involving a thermostat. The Advanced Version is generally used when a BAS system or field programming is required. The table below outlines the differences between the two versions.

Note (1): This feature is available in Tracer TU and Symbio Service and Installation App; it is unavailable via the local user interface.

Note: BACnet communicated sensor(s) only supported with Advanced Symbio 700 Board.

 

Symbio 700 service part numbers for reference

 

💡 Note: The small sticker on the face of the board is an internal manufacturing identification. The board will always read X13651735001, regardless of whether it is Basic or Advanced. Please don't use this sticker to identify the controller type.

 

 

How do I know what version of controller I have?

  • The easiest way to determine which version you have is by connecting to the controller with the Symbio Service and Installation App. The app will show the license type on the Home Page. The app must be version 1.0.2 or newer to see this information.
  • Once the controller reboots, reconnect to the controller using the Symbio Service and Installation App. Navigate to Home > Show More. The License Type will show Basic or Advanced.

 

 

 

NEW in December 2023:

  • Additionally, you can use the Symbio Mobile App to determine which type of controller you have. A Symbio 700 controller with firmware v5.00.0010 or later versions will indicate the type of controller on the onboard display during the boot-up process.

 

Tracer TU 11.9 or higher:

  • The Basic or Advanced version can be viewed from the controller Status Tab, Controller frame, License Type

 

 

Part Number:

  • FRW00001 - Symbio 700 Advance License

 

Key Features:

  • No controller board change will be required
  • License file can be downloaded or delivered via e-mail
  • Symbio Service and Installation App or on-board display will be used to update the license (Tracer TU licensing support coming later in 2024)

 

How to obtain a Symbio 700 Advanced License:

  • License can be purchased through Trane Parts.

  • After ordering, you will be emailed an Advanced License Software Serial number and a link to Trane Controls Licensing - Salesforce.

    Note: if you do not receive an email within 3 business days, please contact Order Management team for assistance.

How do I apply the new license file in the Symbio 700 unit controller:

  • Installation Instructions will be provided in the email, along with the license file. Please take a look at the instructions below.

Download Firmware:

🛑 Alert: Minimum firmware required: Precedent, Voyager 3, Odyssey - V6.00.0010.

💡 Note: The preferred method for upgrading the firmware and applying a new license to the Symbio 700 controller is by using the Symbio Service and Installation App.

  • Visit Trane.com and download the latest Symbio 700 firmware. Firmware Download - Click Me
  • Copy the firmware to the USB storage device. Save the firmware in the root folder of the USB drive and not in a subfolder. The Symbio 700 controller can only read a file in the root folder.
  • How to update the firmware: Symbio™ 700 - Firmware Update for Unit Controller Module – Trane Commercial HVAC Help Center

 

Update the New Controller Firmware:

  1. With the unit and the controller powered, insert the USB storage device with the latest firmware into the Symbio 700 USB port J2 (see Figure 1).
  2. Using the Symbio Service and Installation App, connect to the new controller.
  3. Navigate to Tools > Update Firmware and perform a firmware update to the new controller (see Figure 2).
  • Note: Updating the controller firmware may take up to five minutes. During this time, the Bluetooth connection is lost and unavailable. Please follow the update on the Symbio 700 onboard user interface.

 

 

Apply Symbio 700 License:

After obtaining a license for the Symbio 700 controller, a confirmation email is sent containing the license file. Use one of these three methods for applying the advanced license to the Symbio 700 controller:

  • Method A: Apply a license from a mobile device using the Symbio Service
    and Installation App (preferred method for Contractors)
  • Method B: Apply a license from a USB drive using the Symbio Service and Installation App
  • Method C: Apply a license from a USB drive using the on-board display
  • Method D: Apply a license file using Tracer TU (preferred method for Trane Technicians)

 

Important:

  • Each license file is specific to the Symbio 700 serial number. The license filename contains the serial number of the matching Symbio 700 Controller. Confirm that both the license filename and the serial number of your Symbio 700 controller match.
  • After downloading the license file, confirm the file extension is ".lic" and that the file name has the same structure as shown in Figure 3.

Figure 3. Symbio 700 Advanced License File

Method A: Apply a License from a Mobile Device Using the Symbio Service and Installation App

  1. Download the license file from the confirmation email to a mobile device. The license file name contains the Symbio 700 serial number and customer name. The file extension is “.lic”.
  2. Use the Symbio Service and Installation App to connect to the controller.
  3. Navigate to Tools > Update License.
  4. Select Upload License From Mobile Device (see Figure 4).
  5. Tap ...select a license file-. Browse files and select the license file to apply to the controller (see Figure 5).          
    • Note: To easily locate the license file, select the search feature and search for .lic. The search results will contain all .lic files found on the mobile device.
  6. Select UPLOAD LICENSE FROM MOBILE DEVICE.
  7. A confirmation screen indicates that the license upload started successfully. Tap OK. Important: Please note that the license upgrade process will not begin until you tap OK, make sure that you do not exit the app before doing so.
  8. The Symbio 700 controller will reboot and the connection will be lost during this time. (see Figure 6)

 

Method B: Apply a License from a USB Drive Using the Symbio Service and Installation App

  1. Copy the license file to the USB storage device. Save in the root folder of the USB drive and not in a subfolder. The Symbio 700 controller can only read a file in the root folder.
  2. Insert the USB storage device with the license file into the Symbio 700 USB port J2 (see Figure 7).
  3. Navigate to Tools > Update License.
  4. Select Upload License From USB. The Symbio 700 controller scans the USB storage device and detects all license files in the root file (see Figure 8).
  5. Tap ...select a license file-. Browse files and select the license file to apply to the controller. If the USB storage device contains multiple license files, select from the list of all license files provided (see Figure 8).
  6. Select the license file. Confirm that it matches the serial number of the Symbio 700 controller.
  7. Select UPLOAD LICENSE FROM USB.
  8. A confirmation screen indicates that the license upload started successfully. Tap OK. Please note that the license upgrade process will not begin until you tap OK, make sure that you do not exit the app before doing so.
  9. The Symbio 700 controller will reboot and the connection will be lost during this time (see Figure 9).

 

Validate Advanced License Using Symbio Service and Installation App

  • 1. Once the controller reboots, reconnect to the controller using the Symbio Service and Installation App.
  • 2. Navigate to Home > Show More.
  • 3. Confirm that the License Type is Advanced.

 

Method C: Apply a License from a USB Drive Using the Onboard Display

  1. Copy the license file to the USB storage device. Save the file in the root folder of the USB drive and not in a subfolder. The Symbio 700 controller can only read a file in the root folder.
  2. Insert the USB storage device with the license file into the Symbio 700 USB port J2 (see Figure 1).
  3. Using the on-board display, navigate to Utilities > About > Update License.
  4. Press enter. (see Figure 11)
  5. The license file displays at the top of the screen. If the license is valid and corresponds to the serial number of the Symbio 700, Enter to License displays on the controller. If the license is invalid, a Not Valid message displays. *Note
  6. Press enter to apply the new license.
  7. On the confirmation screen, use the up and down arrows to select Yes and press enter. (see Figure 12)
  8. The Symbio 700 controller begins applying the new license. During this process, the controller reboots.
  • *Note: If the USB storage device contains multiple license files (with the “.lic” extension), use the up and down arrows to select the correct file

Validate Advanced License Using On-Board Display

  1. Once the controller reboots, use the onboard display to navigate to Utilities > About > Controller License.
  2. Confirm that Advanced License displays under controller license. (see Figure 13)

Figure 13. On-board display validate advanced license

 

Method D: Apply a license file using Tracer TU

 

 🛑 Alert: Minimum Tracer TU version required: V12.

  1. Download a copy of the license file to your computer
  2. Connect to the Controller using Tracer TU. Once connected, navigate to File Transfer Utility, from the list of devices, select only the Symbio 700 controller, then click Next, (see Figure 14).
  3.  Choose the license file by selecting Browse from the menu on the right side. A select file window will open. Navigate to and select the license file you want to apply, click Open and then Next, (see Figure 15 & 16).
  4. The controller will apply the license and reboot. 
  5. When the process is completed, a successful message will appear on the File Transfer window. Click Finish (see Figure 17).

Validate Advanced License Using Tracer TU

  1. Once the controller reboots, navigate to Status Utility > 7. Controller Status.
  2. Scroll down to the Controller container and confirm that Advanced License displays under License Type. (see Figure 18).
