Space Humidity Sensor

 

Wiring

Recommended Wire

  • Analog input wire must be 18-gauge shielded twisted pair (Trane Purple Wire) or equivalent to Trane wire number 400 2028.

Sensor Wiring

  • Pull the terminal blocks straight up off the circuit board to reveal the Humidity (+ and --) and TEMP designations.

Alarms

On Symbio 700, if no Space Humidity sensor is connected to UC-J23 and the configuration is set up for a Space Humidity Sensor = Installed

  • Space Humidity Active 
  • Space Humidity Input

On ReliaTel units, the unit will not alarm for space humidity if the sensor is not installed, but will alarm if the sensor was reading and stopped. ReliaTel will report 

  • Diagnostic: Space Humidity Active

 

To enable a Space Humidity Sensor on Symbio 700 from the Symbio app:

  1. Goto SETTINGS>VIEW CONFIGURATION>EDIT>PROCEED
  2. Set Space Humidity to INSTALLED
  3. Press the blue SAVE/APPLY/Check Mark at the top right corner of the page

On ReliaTel, you only need to connect the sensor and it will start reading, but the unit will need to have the associated wiring inside the unit. A unit with the wiring will have the low voltage terminal block show above with terminals 18 & 19 wired back to RTOM J8-4 & 5.
