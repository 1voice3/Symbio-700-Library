Symbio™ 700 - Using Trane® Tracer TU to edit or configure configurations

Overview

You can configure and edit the Symbio™ 700 using Trane® Tracer TU through the Equipment Utility interface. This workflow gives access to the controller’s configuration parameters, allowing users to review, modify, and apply unit-specific settings. To begin, navigate to the Configuration tab within Equipment Utility and select Edit. When you enter edit mode, the system displays a prompt indicating that the equipment must be stopped before you can make configuration changes. After confirmation, click the Edit button; the controller configuration becomes editable by section.
 
If the Symbio™ 700 controller has been replaced, each configuration section must be completed and verified to ensure the new controller is properly configured. Proper configuration is essential for correct unit operation and overall system performance.
 

Important

  • Changing the Equipment Type clears the current configuration from the controller. As a result, the unit must be manually reconfigured, and the previous configuration, including the factory default restore state, is lost.


Steps to enter config mode 

1. Click on the right tab, Equipment Utility

 

2. From the Equipment Utility page, click on the top Configuration tab

 

3. On the Configuration screen, click the Edit button

 

4. A dialog box shows up; Stopping the Equipment dialog box will appear; click the Yes button to continue

 

5. When the unit has been configured, you can edit each section, and when the Symbio™ 700 has been replaced, you need to fill in each section.
