Emergency Stop or Equipment Shutdown Input

 

Notes

Note: Emergency Stop on the Symbio 700 UC-J18 is normally open. (Equipment Run)

Note: External Auto Stop (in the configuration menu) will require a Customer Connection Module.

 

J18 Input Field connections

  • To wire a field-installed Smoke Detector contact or other shutdown device to the Symbio unit, use the J18 terminals on the Symbio 700 UC.

 

 

 

Diagnostic Generated

Diagnostic generated when the input is in it's alarm state will be Diagnostic: Equipment shutdown input status.

The alarm state can be either normally open or normally closed depending on the Symbio 700 polarity setting which is dependent on the connected device contacts. 

See Changing Polarity section for more details.

Changing Polarity

  • The contacts are default to normally open (closure between UC-J18-1 and UC-J18-2 will shut the unit down)
  • This can be changed with the Customer Connection Polarity feature in the Symbio Mobile Phone App.
    • It's in Tools at the bottom of the page.
    • Click the link below for more information
      • https://support.trane.com/hc/en-us/articles/360060801931-Symbio-700-Emergency-Stop-Polarity
