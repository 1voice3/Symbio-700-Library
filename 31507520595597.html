Symbio™ 700 - How to Change from a Zone Sensor to a Thermostat Control

Change Zone Sensor to Thermostat Control

If the Symbio has an Advanced controller module from the factory, the Space Controller defaults to a Single Setpoint Zone Sensor.  You can follow these steps to change from a zone sensor to a conventional thermostat control on a Symbio 700 Unit Controller Module. 

Note: Unit Controller J21 terminal explanation

  •  https://support.trane.com/hc/en-us/articles/8006597703437-Symbio-700-Thermostat-J21-Terminals

 

Configuration Steps

  • Click the Settings tab from the Home page on the Symbio Service & Installation App.
  • Click the View Configuration tab from the Settings page.
  • The Space Controller is set for a Single Setpoint Zone Sensor. In the top right corner, click the Edit button.
  • Click the Proceed button.
  • Click the Space Controller tab.
  • Notice that the Apply button is disabled. The Apply button will be enabled once you change from a Single Setpoint Zone Sensor to a Convention T-Stat. Click the Apply button.
  • Now you can see the change, but click the Apply button to SAVE that configuration.
  • Click the Home tab at the bottom, and the thermostat inputs appear on the Home page.
