Steps for Replacement

Alert Notice

  • Zero Out-of-Box Config: Do not forget to back up the original controller first if it is still responsive. If the original controller is completely dead, you will need to manually configure it using the Mobile App or Tracer TU.
  • Firmware Mismatch: Always verify and flash the unit to the latest approved firmware version before restoring the configuration to prevent database corruption.


Overview

Replacing a Symbio 700 unit controller follows a four-step process designed to ensure a smooth transition and minimize setup issues. Before beginning, follow all company safety procedures and properly power down the equipment. First, back up the existing controller configuration to a formatted USB drive using the mobile app. This is the recommended method, although Trane technicians may also use Tracer TU. This backup lets you restore the current settings to the new controller, provided the original controller is still functional. Next, complete the physical controller replacement. After the new controller is installed, update it with the latest firmware. Then, restore the saved configuration to the new controller or complete the setup manually through the app, as needed.

When followed properly, this workflow helps maintain system settings, supports compatibility with the new controller, streamlines the replacement process, and promotes safe service practices
