Symbio 700 - Restore to Factory Defaults

 

Summary

The Symbio App allows you to reset the Symbio 700 board to factory defaults only if it is the original from the factory. This operation can be performed through the Symbio App. If the board has been replaced, no factory default setting is present, and the board will have to be manually configured. The illustration shows the steps to reset the board to factory default through the App.  

 

🛑 Alert: Before restoring to factory defaults, verify that there are NO custom points or programs. If there are custom points or programs, please contact your local Commercial Sales Office. If you are a Trane Technician, please contact Controls Technical Support.

 

 

Create a backup file.

  • https://support.trane.com/hc/en-us/articles/18364850907405-Symbio-700-Backing-up-your-data-to-restore-your-configurations-and-settings

 

Restore 

  • In the Symbio App, navigate to the Tools menu
  • Select the Restore item from the menu
  • Select the Restore Factory Defaults
  • Press the Restore Factory Defaults icon
