Voyager 3 w/Symbio 700 - Cooling will not Energize in Service Mode

VoyagerCompressor / Compressor ProvingTroubleshootingCommunications / BACnetInstallation / StartupHeatingManuals / Literature
Section: Voyager 3  •  Category: Large Commercial RTUs | Splits | CSC
Created: 2026-03-20  •  Last updated: 2026-08-06

The Large Commercial Team have been getting multiple calls on the cooling/compressors not energizing when initiating the Service Test Cooling modes.  In most of these cases there are no diagnostic present and the unit is configured as a VVDA system (Multi Zone VAV). When the unit is configured for VVDA the "6 Minute VAV Box Timeout Request" is active even in Cooling Mode (this is new with Symbio 700...with Reliatel Controlled units the 6 Minute timeout was only active for Heat).  So as long as there are no diagnostics that would specifically inhibit/disable the Cooling functions the compressors should energize after ~6 minutes.  See the snip below of the Application Guide for Voyager 3 with Symbio controls.
