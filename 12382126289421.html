Used With

 

Installation Instructions

Click the e-library symbol for the latest version of the Clogged Filter Switch Installation Instructions.

 

Note

 

  • An options board (FIAOPTN002*) must be installed in the unit for this accessory to operate.
    • https://support.trane.com/hc/en-us/articles/40502139474061-Symbio-700-Field-Installed-Fresh-Air-Options-Module-Installation-Guide
  • This accessory kit detects static pressure differentials across the filters to indicate a clogged or dirty filter condition. When it detects such a filter problem, the Symbio™ 700 will annunciate a filter change required alarm

 

Installation

Setting

  • The pressure switch is factory preset at 0.45-inch WC (1.12 mbar) for FIACLFS001/3/5* and 0.75-inch WC (1.87 mbar) for FIACLFS002/4/6*.

 

Location

Cabinet B and C

Cabinet D

Cabinet A

 

Wiring

  • Using the control harness included in the kit, connect PPF86 from the harness to the connector on the clogged filter switch.
  • Route the harness up the right side of the return enclosure and through the opening where the factory wires lead to the fresh air module inside the enclosure.
  • Connect J15 of the harness to P15 on the fresh air module.
  • Secure the harness with factory-installed wire ties using the releasable feature on each wire tie.

 

Configuration

Phone App

 

Using the Symbio 700 Onboard menu and keypad

  1. Press Home.
  2. Press the Down Arrow and select Utilities.
  3. Press the Check.
  4. Press the Down Arrow and select Unit Config.
  5. Press the Check.
  6. Press the Down Arrow and select Edit Unit Config.
  7. Press the Check.
  8. Press the Down Arrow and select Clogged Filter.
  9. Press the Check.
  10. Press the Down Arrow and select Installed.
  11. Press the Check. 
  12. Press the Down or Up Arrow to Save Config. 
  13. Press the Check. 
  14. Press the Down Arrow to change No to Yes.
  15. Press the Check.
  16. It will say Edit Unit Config Updating.
