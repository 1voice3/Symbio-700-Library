Symbio Touch Screen Display Configuration For Remote Sensor

General Symbio 700Wiring / Wire PairingSensors / ModulesInstallation / Startup
Section: WSHP UC400 & Symbio 400-B & 500 Control  •  Category: Water-Sourced Heat Pumps
Created: 2026-03-19  •  Last updated: 2026-07-20



The following sensors are capable of having a remote 10K type II mounted externally from the sensor in the space for control.
 

Symbio™400/UC400: X13790993 (SEN02587)

ReliaTel™: X13790994 (BAYSENS924)

Symbio™ 700/800: X13791009 (BAYSENS800)

 

 

Any of Trane's Zone sensors will work with this sensor will work with this sensor as they are all 10K Type II.  Setpoint is not required, Sen01448 is recommended.

 

Steps:

  1. The sensor is wired to terminals 17 and 18 of the unit.
  2. The configuration of the inputs must be set as well as the type of sensor.  This is done from the Configuration Menu 2/4.  
  3. To enter the menu:

     
  4. Navigate to the 2/4 Configuration page
  5. Set the UC17 config from None to Temp
  6. Set the Temp. sensor from Internal to Wired, DO NOT set for remote

 

If multiple sensors are needed, 4 sensors must be added at one time and wired in a series parallel configuration as shown below.  This is for the temperature only version of the sensor.  Setpoint, Fan and On/Cancel is not supported.
