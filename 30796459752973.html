Updating Symbio Firmware From the Symbio Web User Interface Without Tracer TU

General Symbio 700Firmware / SoftwareCommunications / BACnet
Section: Symbio  •  Category: Building Automation | Integration | Service Tools
Created: 2024-10-04  •  Last updated: 2026-09-14

Symbio Firmware can be updated in the field without the need for Tracer TU.  Users will need a USB A to B cable (printer cable), a laptop and the firmware.

Steps to update the Symbio Firmware using the built in Web UI

  1. Download the latest Symbio Firmware from the Trane Software Downloads Site to a known place on your PC.  The download site can be found here: https://www.trane.com/commercial/north-america/us/en/products-systems/building-management---automation/trane-controls-software-downloads.html 

  2. Connect the USB A to B cable to the Symbio and to the laptop.  The image below shows were to connect the USB cable to the Symbio.

    Note

    The Symbio 800 must be powered for this process to work. Symbio 210, Symbio 400B and Symbio 500 can be powered from USB.

  3. In a browser type or paste the following http://198.80.18.1 

  4. Select Log In

    Note

    If security was enabled a user name and password will be required.

    Technical support will not know the user name or password of the locally configured User.

     

  5. Select Tools and then select Firmware from the Tools list.
    Note: It is highly recommended to backup the controller before proceeding.  This can be done in the Backup and Restore options under tools.

     

  6. To select the firmware file to be uploaded to the controller,  press the Select Button that is boxed in red below.

     

  7. Browse to where the firmware file was saved in step 1, select the file.  The selected file will appear in the file Name dialog in the bottom left of the screen.  Select Open.

     

  8. Select Upload

     

  9. A popup will appear, select Continue to confirm that the device will restart.

     

  10. The web UI will show Uploading followed by restarting.  On the Symbio 800 the 7 segment display will show U21.  This will continue for about 6 minutes followed by the controller rebooting and the seven segment display going to a dancing vertical line pattern indicating normal operation.

     
  11. Once the controller has been successfully updated, the Web UI will display Success.  Select OK to continue.

The controller firmware has been successfully upgraded.
