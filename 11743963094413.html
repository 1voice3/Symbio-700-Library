Identify the Firmware Version

There are several ways to identify the firmware version of the Symbio 700 Unit Controller. You can verify the version through the User Onboard Interface, Symbio Phone App, or Trane® Tracer TU. These options offer different ways to access and determine the firmware version installed on your device.

 

Using the onboard display

  • Method 1 to identify the firmware version is to use the Symbio 700 onboard display. Navigate through the main menu to Utilities and then select About. The current software version will scroll across the screen. 

 

 

Using the onboard display

  • Method 2 using the Symbio 700 phone app. From the home screen, you only need to scroll to the bottom of the page to see what version is installed. See the image below.

 

 

 

Using the Trane® Tracer TU

  • Method 3 using Trane® Tracer TU. Once connected, select the Controller Status tab and scroll to the bottom, where you will find the controller information drop-down and the installed product version (Firmware version).
