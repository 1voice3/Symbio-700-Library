Economizer Not Operating - 2023 6-25 ton Precedent Unit

PrecedentVFD / DrivesFirmware / SoftwareSensors / ModulesEconomizer / VentilationCommunications / BACnetInstallation / StartupHeatingSafety / Emergency Stop
Section: Symbio 700  •  Category: Light Commercial Rooftops | Splits
Created: 2023-04-24  •  Last updated: 2026-09-16

Subject:

We are recommending the upload of the latest Symbio 700 unit controller firmware 3.00.0012 (or higher) to ensure proper economizer operation. The firmware upgrade is recommended whether the unit currently has an economizer or not. The action described in this Article is NOT being taken to address a safety concern.

 

Problem/Issue:

There may not be economizer operation on some 2023 Precedent units with Symbio 700 firmware versions 3.00.0009 or 3.00.0011.  There may not be a 24VAC input to the economizer actuator resulting in no economizer movement/operation. This can be verified by checking the voltage at pin 1 of the P8 connector (P8-1) for the presence of 24VAC and/or by simply verifying the Symbio 700 unit controller has the latest firmware (3.00.0012) installed through the Symbio 700 phone App.

**For field installed economizer, Symbio™ 700 configuration parameter Outside Air, must be configured for 0 to 100% Economizer.

 Affected Units:

3 - 12.5 ton Precedent units built in Lynn Haven, FL with Unit Serial # range 230100000L through 231611081L.

12.5 – 25 ton Precedent units built in Clarksville, TN with Unit Serial # range 230100000D through 231610096D.

 

Solution:

Update the Symbio 700 unit controller firmware to the latest version: 3.00.0012 (or higher) by utilizing the instructions available in the referenced Resource links.

**For field installed economizer, Symbio™ 700 configuration parameter Outside Air, must be configured for 0 to 100% Economizer.
Important. USB thumb drive, download of firmware, and download of app will be required prior to dispatching to jobsite. Review all instructions closely prior to dispatching to jobsite
