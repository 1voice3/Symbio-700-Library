Symbio® 700 Customer Connection Module (CCM) not communicating

Troubleshoot

 

 

Does the CCM Module have power?

  • Verify that LED 8 is solid green in the middle of the module, and LEDs 5 & 6, located under the P4 connector, are lightly flickering. 

 

  • Verify CCM-P5 has 24VAC between Red and Black
  • Verify CCM-P5 has 3.2 - 3.9 VDC between Blue and Orange

 

  • If CCM-P5 does not have VAC or VDC, verify that AB-J19 has 24VAC between Red and Black and/or AB-J19 has 3.2-3.9VDC between Blue and Orange. 
  • If there is no power on AB-J19, verify that AB-J8 is powered between the Blue and Orange wires.
  • If there is no power on AB-J8, verify PPF72/PPM72 between the Blue and Orange wires.
  • If there is no power on PPF72/PPM72, verify PPF2/PPM2 between the Blue and Orange wires.
  • If there is no power on PPF2/PPM2, verify TNS2.

 

 

 

 

Does the Factory-Installed module have the address plug?

  • The Customer Connection Module, when factory-installed, includes an address plug pre-installed on J11. The factory plug is already configured for address 78. 
  • The rotary dials should be set to 00.
  • If the Customer Connection Module says "Not Communicating" on the mobile phone app under Tools > Service, try the steps below.
  • If the address plug is securely connected and you have verified the address on the plug, remove the plug and set the rotary dials to 78 (SW1 to 7 and SW2 to 8).
  • Cycle power to the unit or reset the IMC link through the mobile phone app. Go to Tools > Service > scroll down to IMC LINK RESET.

 

 

 

 

Is the Field-Installed module addressed?

  • The field-installed Customer Connection Module must be addressed to address 78 on the provided rotary dials.
  • SW1 is addressed to 7
  • SW2 is addressed to 8 
  • To verify the communication status, go to Tools > Service on your mobile phone app.

 

 

 

 

Is the CCM configured?

  • To verify the communication status, go to Tools > Service in your mobile phone app.
  • When it says Communicating, there should be no active alarms for the Customer Connection Module.
  • When it says 'Communicating - Not Configured,' it means the Customer Connection Module is communicating, but there is no configuration associated with it. This will show two active alarms.
  • You must configure the CCM under Settings > View Configurations> Edit.

 

Please click the link below to view the configurations.

  • https://support.trane.com/hc/en-us/articles/44710307874829-Symbio-700-How-to-Configure-a-Customer-Connection-Module

 

  • When the Customer Connection Module is not communicating with the Symbio 700 and the unit does not have one, the Symbio 700 configuration is incorrect. 
    • These points must be verified (Should be set to not installed).
      • Remote Minimum Position
      • External Auto/Stop
      • Ventilation Override
      • Alarm Indicator
      • Humidistat

 

 

 

 

Alarms

  • Customer Connection Module Communication Status
  • Diagnostic: Unit Communication Failure
