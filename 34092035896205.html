Emergency Stop Polarity

  • The Symbio 700 Phone App features useful functionality that allows users to modify the operation of the Emergency Stop input. With this feature, users can customize these inputs according to their specific needs and preferences.

 

 

Equipment Shutdown Input Status (UC J18-2)

  • If the Equipment Shutdown Input Status is set to Normal, a 24 VAC Input on UC J18-2 will immediately shut down the unit.
  • If the Equipment Shutdown Input Status is set to Reversed, a 24 VAC input on UC J18-2 is needed for the unit to run.

 

 

Customer Connection Polarity

Phone App

  • This feature is in the Tools Menu
  • You can change the operation of the Emergency Stop input with this feature in the Phone App.


This will support either a Normally Open or a Normally Closed Shutdown Device.

 

 

 

Tracer TU

  • Click Utilities > Equipment > Service

 

  • Expand the Customer Connection Input Polarity box to change the Equipment Shutdown Input Status.
