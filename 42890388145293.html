Symbio 700 Data Log Information

  • Symbio 700 by default data logs many crucial points by itself, but can also have more data logs added using Tracer TU. 
  • The default data logs sample every 10 seconds for 50,000 samples providing 5.89 days of data
  • The Symbio platform exports data logs as individual *.csv files that can be viewed individually using Microsoft Excel or any program that can open *.csv files. 
    • Unfortunately, the Symbio platform does not combine the files as one large file on export.

Do you have access to Tracer TU → Symbio™ 700 - Retrieving Data Logs with Tracer TU

 

 

Retrieving Data Logs with the Symbio App

 

 

  1. Connect a USB thumb drive in the USB port on the top left of the Symbio 700
    • Flash drive must be 1GB or larger and using FAT32 file format
  2. Connect to Symbio 700 with Symbio Service & Installation Mobile App using Bluetooth. 
    • Click this link for instructions on how to connect → Symbio™ 700 - Bluetooth Connection Instructions
  3. Navigate to TOOLS>EXPORT DATA LOGS:
  1. Select "Export Data Logs"
  1. Symbio 700 will start exporting the data logs to the USB, do not power down the controller and allow the app to finish before navigating away. 
    • Note: Symbio 700 will continue to operate as normal in the background. 
  1. The app will alert when the data log export is complete
  1. Once the logs are on the USB, they can be viewed with Microsoft Excel or any application that allows viewing of *.csv files. 
  • Symbio does produce a separate file for every data logged point. 

 

Viewing Data Logs on the Symbio App

 

 

  1. Connect to Symbio 700 with Symbio Service & Installation Mobile App using Bluetooth.
    • Click this link for instructions on how to connect → Symbio™ 700 - Bluetooth Connection Instructions
  2. Navigate to TOOLS>VIEW DATA LOGS:
  1. Select the desired data logs to view from the list (up to 4 logs) and select "View Multiple":
  1. The app will display the selected logs over the first day of the available data
  1. The user can the time frame and day by selecting the blue text at the top of the screen:
  • Then you can narrow the time frame of the day:
  • Then the user can select what day and what time (set day first then app will prompt for what time):
  • Clicking the data points on the screen will show the value of that point
