Discharge Air Sensor

 

Note

  • The discharge air sensing tube is standard on SZVAV, MZVAV, hot gas reheat, heat pump, modulating gas, eFlex, and economizer units, and is configured to be shown as Installed in the configurations.
  • After installation is complete, the Symbio 700 UC module configuration must be updated to enable the installed accessory.

 

 

Installation Instructions Manual

Click the e-library symbol for the latest version of the installation guide.

 

 

Wiring

For detailed instructions, please reference the installation manual.

  • Connect PPF177, which is factory-installed in the unit and is located in the general area where the discharge temperature sensor is being mounted, to PPM177 from the sensor.

 

Configuration

Using the Symbio 700 Onboard menu and keypad

  1. Press Home.
  2. Press the Down Arrow and select Utilities.
  3. Press the Check.
  4. Press the Down Arrow and select Unit Config.
  5. Press the Check.
  6. Press the Down Arrow and select Edit Unit Config.
  7. Press the Check.
  8. Press the Down Arrow and select Discharge Temperature Sensor.
  9. Press the Check. 
  10. Press the Down Arrow and select Installed.
  11. Press the Check. 
  12. Press the Down or Up Arrow to Save Config. 
  13. Press the Check. 
  14. Press the Down Arrow to change No to Yes.
  15. Press the Check.
  16. It will say Edit Unit Config Updating.
