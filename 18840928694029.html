Voyager 3 Process of connecting a BAYSENS800 to an Symbio 700 Controller

VoyagerFirmware / SoftwareSensors / ModulesCommunications / BACnetInstallation / StartupHeating
Section: V3 w/Symbio 700 controls  •  Category: Large Commercial RTUs | Splits | CSC
Created: 2023-08-24  •  Last updated: 2026-07-15

Overview:

The BAYSENS924 will not work on the Symbio 700 you need a X13791009001 (BAYSENS800)

The BAYSENS800 is NOT Compatible with VAV/VVDA configured systems and units (VVZT only).

You also need a BACnet-enabled Symbio 700 UC. 

If the Voyager 3 wasn't ordered with a BACnet-enabled Symbio 700 UC (Digit 26 of the Model number ="0"), 

Model Number Digit 26 = A or B (Advanced Controller with BACnet), the only way to get it in the field at this time is to replace the Symbio 700 with a version that has BACnet enabled (MOD03103)

In the BAYSENS800 - Set temp sensor to internal.

 

 

Symbio 700 Configuration

BAYSENS800 Setup in the Phone App:

  • Verify the unit has an Advanced UC module
  • Set Symbio 700 UC rotary dials to 001

On the Phone App go to Settings < System and set Arbitration Method Request to Enable External BAS Control

In Settings < View Configuration < Edit set Space Controller Type to Single Setpoint Zone Sensor

  • Verify SYSTEM TYPE IS CVZT or VVZT (BAYSENS800 is not compatible with VVDA)

In Tools < Protocol Configuration < Protocol set to BACnet MS/TP - 76800, then SAVE

 

 

Communication Wire

Use the correct communication wire to ensure reliable communication between the zone sensor and the HVAC equipment. (C-(13), D-(14) to J17-1, J17-2 and E-(15) to J21-9 (Shield wire))

 

  • Suggested Supplier: Windy City Wire:
  • Plenum rated P/N: 043005AL
  • Non-plenum rated P/N: 108760

 

  • Other wire may be used if it conforms to the following physical characteristics:
  • Twisted pair (2-conductor) plus shield.
  • Characteristic Impedance: 100 and 130 ohms.
  • Distributed capacitance between conductors: < 100 pF/m.
  • Distributed capacitance between conductor and shield:
    < 200 pF/m.
  • Foil or braided shield is acceptable.
  • Wire diameter: 22 to 18 AWG.

 

BAYSENS800 Configuration

 

To enter configurations

Password to enter configuration mode 4017

 

BAYSENS800 Sensor (old firmware version with 2 network pages):

  • Set the temp sensor to internal
  • Sensor Address = 2
  • Unit address = 1
  • Baud rate = 76,800
  • Password to enter configuration mode 4017

 

BAYSENS800 Sensor (new firmware version with 3 network pages):

  • Set the temp sensor to internal

    See Figure 4 below:
  • Network Page 1
    • Sensor Address = 2
    • baud rate = 76800
  • Network Page 2
    • Sensor device ID set to 0000002
  • Network Page 3
    • Unit device ID set to 0000001

Make sure to hit the next button (right arrow) to save changes
