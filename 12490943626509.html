Customer Connection Module 

 

Summary:

This kit is required when adding a humidistat, ventilation override, remote minimum position, external auto/stop, and alarm indicators. The Customer Connection module operates with the Symbio 700 in the condenser to provide logic control.

 

 

 

 

Click the e-library symbol for the latest version of the installation guide

 

 

 

Module Address

  • In the Customer Connection module, when it is field-installed, set the address rotary switches to 78. This is required to integrate the module with the Symbio controller. If the Customer Connection module was powered up before setting the address, reset the IMC link. To reset the IMC link, go to Tools > Service > scroll down to IMC LINK RESET.
