A2L Leak Sensor Polarity Correction

 

Background: 

There is an issue with V6.00.0011 to V7.01.0014 firmware for Symbio 700. The LDS sensor for A2L on the air handler is a closed relay for normal operation. The closed relay erroneously causes a "Diagnostic: Refrigerant Sensor Concentration Sensor A" on the Symbio 700. 

 

Corrective Actions:

  • Ensure firmware is V7.01.0016 or newer, or update Symbio 700 firmware accordingly
  • Reset Configuration by changing the Refrigerant type

 

Step 1: Check the firmware version in the Symbio 700

Firmware Version Check:

Symbio™ 700  - How to Identify the firmware version of the Unit Controller

If the firmware is below V7.010016, proceed to Step 2. 

If the firmware is V7.01.0016 or higher, proceed to Step 3. 

 

Step 2: Update the firmware in the Symbio 700

Update the firmware by following the instructions in the article:

Symbio™ 700 - Firmware Update for Unit Controller Module

 

Step 3: Change and Save the configuration to reset the Symbio board

Once the firmware is updated or verified, the refrigerant type will need to be changed from R454B to R410A in the configuration, saved, changed back to R454B from R410A, and saved again.

The articles below demonstrate how to access and change the configuration with the Mobile Phone App and Tracer TU:

Symbio™ 700 - How to configure or edit configurations using the Mobile Phone App

Symbio™ 700 - Using Trane® Tracer TU to edit or configure

Here are the steps to change it in the Onboard User Interface:

Push the Home button:

Push the down button until you reach the Utilities menu and push ✔

Push the down button until you reach the Unit Config menu and push ✔

Push the down button until you reach the Edit Unit Config menu and push ✔

Push the down button until you reach the Refrigerant configuration and push ✔

You will see a curser on the "R" of the R454B begin to blink

Push the down button once until you see the Refrigerant R410A and push ✔

Push the up button until you reach the Save Config menu and push ✔

The controller will ask you if you want to restart the equipment

Push the down button once until you see Yes and push ✔

Once the Symbio 700 board restarts, go back to the Utilities menu, push the down button until you see View Unit Config menu and push ✔

Push the down button until you reach the Refrigerant configuration and verify it reads R410A

Change the refrigerant back to R454B by following the steps below:

Go back to the Utilities menu

Push the down button until you reach the Unit Config menu and push ✔

Push the down button until you reach the Edit Unit Config menu and push ✔

Push the down button until you reach the Refrigerant configuration and push ✔

You will see a curser on the "R" of the R410A begin to blink

Push the down button once until you see Refrigerant R454B and push ✔

Push the up button until you reach the Save Config menu and push ✔

The controller will ask if you want to restart the Equipment. Push the down button once until you see Yes and push ✔

You can verify that the refrigerant configurations have changed to R454B by going to the Utilities>View Unit Config and push the down button until you reach the Refrigerant configuration. Verify it reads R454B.

Is there a related published service bulletin for this issue? 

Yes, Mandatory bulletin number SS-SVB029A-EN / SS-SVC029A-EN Odyssey Symbio 700 A2L Leak Detection Sensor Polarity Correction. File claims following bulletin instructions. 

Are WMS(Warranty Management System) claims allowed for this issue?

File claims following bulletin instructions. 

Does the above information indicate the final resolution?

Yes, final resolution has been confirmed per above.
