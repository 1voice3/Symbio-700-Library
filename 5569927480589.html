Setting Up BACnet/IP Using the Phone App

 

Make sure the app is installed on your phone (see "Where to Get the Symbio 700 Phone App"). After installing the app and connecting to the device (see: "Bluetooth Connection Instructions", follow these steps below to change the BACnet/IP.

 

Video

 

 

Phone App Procedure

Step 1: 

  • Connect with the Phone App. Once you're on the homepage, click Tools. 

 

Step 2: 

  • Select Protocol Configuration.

 

     

 

Step 3: 

  • Press Edit on the upper right-hand side of your phone.

 

 

 

Step 4: 

  • Change by touching the dropdown arrow at Protocol (Image 1). Change it from BACnet MS/TP to BACnet/IP. In this part of the menu, this is where the network number, UDP port, and BBMD can be changed after BACnet/IP is selected and saved. It should look like Image 2 below. Once the changes have been made, Save your changes.

 

Image 1

 

Image 2

  

 

  • Once the configuration has been changed to BACnet/IP, you can open IP Configuration to change the IP address to Static IP. If DHCP is required, it is set up as the default.

 

Step 1:  

  • Select IP Configuration

 

 

Step 2:

  • Select the Edit button to configure all changeable settings.

 

 

Step 3: 

  • Change the IP address to a static IP address. Click DHCP, then select Static (step 3A).

 

 

Step 3A: 

  • Change to Static IP Address

 

 

Step 3B: 

  • Once the Static IP Address is selected, it can be changed to the required IP address, Subnet Mask, and Gateway. 

 

 

 

Step 4: 

  • Changing the DNS from automatic to Static DNS

 

 

 

Step 4A: 

  • Change to Manual DNS

 

 

 

Step 4B: 

On the edit screen, the DNS can be manually changed. Once the Changes have been made, Save your changes then.
