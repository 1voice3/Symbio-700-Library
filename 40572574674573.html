Symbio® 700 - How to Configure an Indoor Options Module

Configuration

Electric Heat

  • Cooling Only Units

    • Primary Heating Source = Electric
    • Primary Heating Type = Stage
    • Primary Heating Stages = 1 or 2

 

  • Heat Pump Units

    • Primary Heating Source = Heat Pump
    • Primary Heating Type = Stage
    • Primary Heating Stages = Full
    • Secondary Heating Source = Electric
    • Secondary Heating Type = Staged
    • Secondary Heating Stages = 1 or 2

 

Using the Mobile Phone App

  1. Connect to the Symbio™ 700 board through Bluetooth.
  2. Select the Settings menu.
  3. Select View Configuration.
  4. Select Edit at the top right of the screen.
  5. Select Proceed to stop the equipment operation.
  6. Scroll down to Primary Heating Source or Secondary Heating Source.
  7. Tap Not Installed.
  8. Select Electric.
  9. Select Save.
  10. Scroll down to Primary Heating Type or Secondary Heating Type.
  11. Confirm this is set to Staged.
  12. Scroll down to Primary Heating Stages or Secondary Heating Stages and tap (1 or 2) --Select One--.
  13. Choose the correct number of stages.
  14. Select Save.
  15. Select Save again in the top-right corner to save all configurations.

 

Using the Symbio 700 Onboard menu and keypad

  1. Press Home.
  2. Press the Down Arrow and select Utilities.
  3. Press the Check.
  4. Press the Down Arrow and select Unit Config.
  5. Press the Check.
  6. Press the Down Arrow and select Edit Unit Config.
  7. Press the Check.
  8. Press the Down Arrow and select Primary Heating Source or Secondary Heating Source.
  9. Press the Check
  10. Press the Down Arrow and select Electric.
  11. Press the Check.
  12. For Primary Heating Type or Secondary Heating Source, press Check, then select Staged.
  13. Press the Check.
  14. For Primary Heating Stages or Secondary Heating Source, press the Check.
  15. Press the Down Arrow to select 1 (stage of electric heat) or 2 (two stages of electric heat) and then press the Check.
  16. Press the Down or Up Arrow until you find Save Config.
  17. Press the Check.
  18. Press the Down Arrow to change No to Yes.
  19. Press the Check.
  20. It will say Edit Unit Config Updating.

 

Note: Must have electric heat connected to IOM-P6 (ELECTRIC HEAT STAGE 1) and/or IOM-P7 (ELECTRIC HEAT STAGE 2)

 

 

Condensate Overflow

  • Condensate Overflow Switch - Installed

 

Using the Mobile Phone App

  1. Connect to the Symbio™ 700 board through Bluetooth.
  2. Select the Settings menu.
  3. Select View Configuration.
  4. Select Edit at the top right of the screen.
  5. Select Proceed to stop the equipment operation.
  6. Scroll down to Condensate Overflow Switch.
  7. Tap Not Installed.
  8. Select Install.
  9. Select Save.
  10. Select Save again in the top-right corner to save all configurations.

 

Using the Symbio 700 Onboard menu and keypad

  1. Press Home.
  2. Press the Down Arrow and select Utilities.
  3. Press the Check.
  4. Press the Down Arrow and select Unit Config.
  5. Press the Check.
  6. Press the Down Arrow and select Edit Unit Config.
  7. Press the Check.
  8. Press the Down Arrow and select Condensate Overflow Switch.
  9. Press the Check.
  10. Press the Down Arrow and select Installed.
  11. Press the Check.
  12. Press the Down or Up Arrow until you find Save Config.
  13. Press the Check.
  14. Press the Down Arrow to change No to Yes.
  15. Press the Check.
  16. It will say Edit Unit Config Updating.

 

Note: Must have a condensate overflow switch connected to IOM-P15 (CONDENSATE OVERFLOW)

 

 

** Supply Air Smoke Detector

  • The Supply air smoke detector is a factory-installed option only.
  • External smoke detector wire up to UC-J18 on the Symbio Unit Controller.
    • Symbio™ 700 - Emergency Stop Input – Trane Commercial HVAC Help Center

 

** STATIC PRESSURE TRANSDUCER

  • The Static Pressure Transducer is a factory-installed component on Multi-Zone VAV units.
