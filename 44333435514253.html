Symbio 700 and 800 - VFD in Hand Mode

There are times when a technician would like to test VFD operation or fan performance by placing the VFD in the Hand Mode.  From the factory this feature is DISABLED because it takes away the ability for the unit to control the VFD during normal operation, VOM override, Emergency Stop and/or Equipment Stop command.  Symbio 700 and 800 units communicate through Modbus communication therefore the Modbus Control Source parameter must be changed as well. 

How to change TR150 VFD parameters on IntelliPak and Voyager 3

Enable Hand Mode

Change parameter 0-40 from Disabled [0] to Enabled [1].

Change parameter 8-02 from FC Port [1] to None [0].

Press Hand Key - should be able to ramp the fan Hz up and down with arrow keys.  

NOTE:

After troubleshooting is complete please be sure to Disable the Hand Feature and change Parameter 8-02 back to FC Port for proper unit operation.
